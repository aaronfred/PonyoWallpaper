> 基于 wallhaven.cc 的桌面壁纸自动更换程序 · Windows 已发布 v1.0.0，macOS 规划中
> 文档状态：与代码同步（随 v1.0.0 发布更新）

## 1. 项目概述

常驻型桌面应用：从 wallhaven.cc 获取壁纸，中文分类浏览 / 关键词搜索 / 多列瀑布流 / 收藏与屏蔽，按设定间隔自动更换桌面壁纸，托盘常驻低占用。核心约束：**界面简洁、占用低、网络在受限环境下开箱即用**。

v1.0.0 交付状态（Windows x64）：

| 形态 | 文件 | 体积 | 说明 |
|---|---|---|---|
| 带环境 | `PonyoWallpaper-1.0.0-x64.exe` | ~48MB 单文件 | 目标机免装 .NET |
| lite | `PonyoWallpaper-1.0.0-x64-lite.exe` | ~740KB 单文件 | 需目标机装 .NET 10 Desktop Runtime |

## 2. 技术选型（最终定案）

| 项 | 选型 | 备注 |
|---|---|---|
| 语言/运行时 | **C# / .NET 10 (LTS)** | 项目启动时的 Python + PySide6 方案在 M0 前被否（GUI 生态与打包体积），改走 .NET；WinForms 桌面壳成熟度无可替代 |
| UI 框架 | WinForms（自绘瀑布流 MasonryPanel） | 原生托盘/热键/UAC；GDI+ 自绘卡片 |
| 网络 | HttpClient + 自建 Socks/Http 代理 Handler | 见 §5 统一请求链路 |
| 数据 | SQLite（history.db）+ JSON（config/favorites/blacklist） | |
| 打包 | `PublishSingleFile`；关键坑：**FDD 必须用 `-p:SelfContained=false` 属性形式**（`--self-contained false` 参数形式在本 SDK 上静默失效，会打出 107MB 的 runtime 包） | |

### 跨平台（macOS）规划：Avalonia

- WinForms 仅 Windows；**macOS 方案选定为 C# + Avalonia**：`Core/` 业务层（约占代码 60%）纯 .NET 可 100% 复用，仅 UI 层重写一次即得 Win/Mac/Linux 三端
- 平台分支点需先抽象：壁纸设置（Mac 用 `NSWorkspace.setDesktopImage`）、hosts 写入（`/etc/hosts` + osascript 提权）、自启（LaunchAgents）、数据目录（`~/Library/Application Support`）
- macOS 分发需 Apple 开发者账号签名+公证（$99/年），个人使用可手动放行 Gatekeeper
- 不采用的方案：Flutter（集成插件质量参差）、Tauri（需 Rust + Web 前端全重写）、Go/Rust 原生 GUI（生态最弱）；Go 保留为"代理池引擎独立服务"的候选（见 §10）

## 3. 功能清单（v1.0.0 实际交付）

### 浏览与更换
- 中文分类树：收藏 → 风景 / 摄影 / 人物 / 动漫（各含二级频道），一级分类聚合视图；分类栏贴边箭头收起/展开
- 关键词搜索（中文→英文 tag 映射，AND 组合 + 三级降级链防空结果）
- **多列自适应瀑布流**：2~6 列随窗口宽度、卡片按真实宽高比不等高、缩略图可视区懒加载、**无限下拉**（到底自动翻页 + 换种子去重，频道耗尽才停）
- 卡片：双击/设为壁纸、收藏（可取消）、右键屏蔽、预览窗连看
- 自动更换：多选频道（精确到二级）、间隔、分辨率（atleast 兜底）、填充模式（填充/适应/拉伸/平铺/居中）、多屏（统一/每屏独立）
- 全局快捷键 Ctrl+Alt+N / P；换一批（random 换 seed、确定性排序随机跳页、空页回退）
- 深浅色主题

### 隐藏设置（密码门禁）
- 入口：版本号连点 5 次 / Ctrl+Shift+K；**无出厂密码——首次唤出时由用户设置**（新密码+确认），之后每次验证；会话级解锁，收起/最小化/重启后重锁
- 内容：wallhaven API Key（NSFW 必需）、NSFW 分类开关（Sketchy/NSFW）、修改密码

### 代理系统（详见 §5）
- 统一请求链路：直连 → 反代 → 用户代理 → 公共代理池（粘性轮换 + 失败切换）
- 代理独立模块 ProxyModule（域名规则 + 配置快照，供其他程序集成）
- 公共代理池：全网 16 源抓取 → 两轮竞速筛选（96 并发快筛 + 复验）→ 最优 5 个；6 小时或不足 2 个自动刷新
- 优选代理（从现有链路实测最快一级切换）/ 优选代理池（抓源全量筛选）/ 更新代理源 / 恢复默认源

### hosts 管理（通用能力）
- 三区：①需要加速的网站（域名，默认 wallhaven 三站点）②源地址（定期更新的 hosts 网址）③git 加速地址（GitHub 前缀）
- ②③各带「更新」按钮：并发实测保留最优 1~3 个回填
- 顶部只读「最新 hosts」展示框（系统 hosts 中本程序标记段，拉取/写入/移除后刷新）
- 更新 hosts（拉取→展示→提权写入）/ 移除 hosts（仅删标记段）/ 打开 hosts
- 提示：hosts 仅用于访问 wallhaven 官网，主链路依赖代理；默认不自动替换系统 hosts

### 维护
- 缓存清理（LRU 清空，报告释放量）/ **完全清理**（两次确认 → 删除全部数据恢复出厂 → 自动重启）
- 设置即时保存即时生效（无需保存按钮）；开机自启；启动最小化到托盘

## 5. 网络与代理架构（核心设计）

### 5.1 统一请求链路

```
直连 → 反代(多行按序) → 用户代理池(可内嵌账密) → 公共代理池
      每级失败自动切换下一级；成功保持粘性；回绕从头
```

- 反代条目启用时**全部请求直连反代**（Worker 境内可达），URL 按前缀改写：`th.wallhaven.cc→反代/th/`、`w.wallhaven.cc→反代/w/`、主站 API 直转
- 关键实现约束：**URL 与 HttpClient 必须在重试循环内按当前链路条目重新计算**（曾因循环外计算导致 failover 后仍打旧地址的 bug）
- 缩略图下载与 API 共用链路状态（`RewriteForThumbs`）

### 5.2 公共代理池自动探测

```
16 个全网源（TheSpeedX/monosans/proxifly/roosterkid/sunny9577/mmpx12/zevtyardt/jetkai…）
→ 抓取去重（~6000 条）
→ 第一轮全量快筛（96 并发 × 8s；并发过高会打满上行造成误杀，128×6s 实测劣于 96×8s）
→ 第二轮存活复验（12 并发 × 12s 精确延迟）
→ 保留最优 5 个，按延迟排序
```

保活策略：6 小时或池内不足 2 个才重探（减少后台动作）。实测认知：免费代理存活率 <1% 且小时级死亡，池子是耗材——**长期稳定方案是反代**（CF Worker 免费额度 10 万请求/天，或自建服务器反代）。

### 5.3 代理独立模块（对外集成）

```csharp
ProxyModule.NeedProxy(url, cfg)   // 域名后缀匹配（默认 wallhaven 三站点，可配置 ProxiedHosts）
ProxyModule.Route(url, cfg)       // 路由决策
ProxyModule.Snapshot(cfg)         // 配置快照 JSON（规则/反代/用户池/公共池）
```

自检：`PonyoWallpaper-1.0.0-x64.exe --proxy-snapshot`。其他程序集成 = 拷贝 `ProxyModule.cs` + 配置字段。

### 5.4 wallhaven API 约束（沿用核实结论）

45 次/分限流（令牌桶 40/min + 429 指数退避）；`resolutions` 精确匹配需配 `atleast` 兜底；purity 110/111 需 API Key；原图直链 `w.wallhaven.cc/full/{前2位}/wallhaven-{id}.jpg`（**文件名带 wallhaven- 前缀**，曾因漏前缀产生 404）。

## 6. 数据模型

**config.json 主要字段**（完整见 `AppConfig.cs`，含旧字段自动迁移）：

```json
{
  "IntervalMinutes": 60, "Resolution": "2560x1440", "Sorting": "random",
  "FillMode": "fill", "Monitors": "all", "RotationChannels": ["..."],
  "ProxyUrl": "", "ProxyUrls": null, "ProxyUser": "", "ProxyPassword": "",
  "CfProxyUrl": "", "CfProxyUrls": null,
  "ProxiedHosts": null, "PublicProxyUrls": null, "PublicProxyUpdatedAt": null,
  "ProxySourceUrls": null,
  "HostsSites": null, "HostsSourceUrls": null, "HostsAccelUrls": null,
  "CacheLimitMb": 2048, "CacheDirPath": "",
  "StartMinimized": true, "Theme": 0,
  "ApiKey": "", "ShowNsfw": false, "HiddenQuery": "", "HiddenPasswordHash": "",
  "Sub": ""
}
```

设计原则：**发布默认空白**（无反代/无用户代理/无 API Key/无出厂密码），公共代理池兜底开箱即用；个人化数据只存在于本机 `%LOCALAPPDATA%`，不进仓库。

**history.db**：applied（id/wallhaven_id/applied_at/channel/resolution/purity/page_url/local_path/file_size/source）+ favorites + blacklist。

## 7. 发布与 CI

- 版本号唯一来源：csproj `<Version>`（`Directory.Build.props` 兜底防 VERSION 环境变量污染）
- 本地发布命令（双形态）：

```bash
# lite（FDD 单文件，~740KB）—— 必须用属性形式！
dotnet publish -c Release -r win-x64 -p:SelfContained=false -p:PublishSingleFile=true -p:DebugType=none
# full（SCD 单文件，~48MB）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true \
  -p:EnableCompressionInSingleFile=true -p:DebugType=none
```

- CI：GitHub Actions，**tag 驱动**（push tag → 同时产出 full 与 lite 双产物附件）
- 自检：`--test-rotate`（搜索→下载→换壁纸全链路）、`--proxy-snapshot`（代理模块 JSON + 规则命中）
- 归档约定：历史版本不入 git（.gitignore 排除 release/），本机按需保留

## 8. 已知限制与风险

| 项 | 现状/对策 |
|---|---|
| 免费公共代理存活率 <1% 且小时级死亡 | 两轮筛选 + 6h 保活 + 失败切换兜底；**长期方案 = 自建反代**（见 docs/反代搭建指引.txt） |
| wallhaven 封锁在 TLS SNI 层 | hosts 方案效果有限，仅作最后备用 |
| WinForms 不支持 Native AOT | 体积优化已做（InvariantGlobalization/裁剪资源/GC Conserve），SCD 48MB 为实际下限 |
| macOS | 规划 Avalonia（见 §2）；分发需签名公证 |
| 单实例互斥 | 跨版本同名互斥体，升级前需退出旧实例 |
