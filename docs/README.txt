Ponyo壁纸（PonyoWallpaper）· 使用说明
========================================

基于 wallhaven.cc 的 Windows 桌面壁纸自动更换程序。
中文分类浏览、关键词搜索、收藏夹、NSFW 分级、自动更换、托盘常驻、低占用。

【两个版本怎么选】

  PonyoWallpaper-1.0.0-x64.exe          ← 推荐（自带运行环境）
    · 单文件约 48MB，目标机免装 .NET，双击即用
    · 后台内存约 150MB（运行时整体内置）

  PonyoWallpaper-1.0.0-x64-lite.exe     ← 轻量版（不带运行环境，同为单文件）
    · 单文件约 740KB，后台内存约 57MB（运行时由系统共享）
    · 需先装 .NET 10 桌面运行时：
      https://dotnet.microsoft.com/download/dotnet/10.0
      （选 Windows Desktop Runtime，x64）

  旧版本全部保留在 archive\ 下，按日期 + 版本号归档，不会被删除。

【运行 / 升级】
  双击 exe 即可。首次启动默认最小化到托盘。
  ※ 替换新版本前，务必先在托盘右键退出旧实例，
    否则单实例机制会拦截新版本，出现"改了设置不生效"的假象。

【主界面】
  左侧分类树：收藏 → 风景 → 摄影 → 人物 → 动漫（各含二级频道）
             · 点击一级分类显示该分类的全部壁纸；点击二级频道看细分内容
             · 分类栏右缘贴边小箭头（◀/▶）可收起/展开，收起后展示区自动扩大
             · NSFW 分类需在隐藏设置中开启（含 Sketchy / NSFW 两个子分类），
               密码解锁后出现，收起窗口/最小化/重启后再次隐藏
  右侧瀑布流：多列自适应（2~6 列随窗口宽度）、卡片按真实比例不等高、
             缩略图滚动懒加载、滚到底部自动加载下一页（无限下拉）
  底部单行  ：自动更换（下拉多选，可精确到二级频道）+ 间隔 +
              分辨率 / 填充 / 排序 / 多屏 + 换一批 / 设置
  卡片      ：双击或「设为壁纸」应用，「收藏」加入收藏夹，右键可屏蔽

【快捷键】
  Ctrl+Alt+N 下一张    Ctrl+Alt+P 上一张（全局生效，托盘后台也有效）

【设置中心（托盘右键 → 设置）】
  缓存配额、当前代理、开机自启、启动最小化、界面主题、清理缓存、缓存地址。
  所有改动即时保存并生效，无需点保存、无需重启。
  · 「当前代理」行实时显示【方式 - 地址】，例如
        反代 - https://your-worker.your-domain.dev
        公共池 - socks5://1.2.3.4:1080
        直连
    代理可能在后台自动切换，这里始终显示真正在用的那一级。
  · 「优选代理」按钮：不抓新源，只从现有链路
    （直连 / 反代 / 用户代理 / 公共池）并发实测，立即切到最快的一级。
    新填了反代地址后点它即可马上生效。
  底部版本号连点 5 次（或 Ctrl+Shift+K）→ 输入访问密码 → 展开隐藏设置：
    · API Key（wallhaven，NSFW 分类必需，支持显示明文）
    · 是否在首页显示 NSFW 分类（含 擦边 / NSFW 两个子分类）
      ※ NSFW 入口是"会话级"的：密码验证通过后出现；
        收起窗口/最小化/重启后会再次隐藏，需重新输密码解锁（防误触设计）
    · 修改访问密码（无出厂密码：首次唤出时自行设置）

【代理管理（设置页底部按钮）—— 独立代理模块】
  访问优先级：直连 → 反代 → 用户代理 → 公共代理池（失败自动切下一级）。
  ① 需代理的网址：代理模块的路由规则，每行一个域名（后缀匹配）。
     默认展示当前代理的站点：wallhaven.cc / th.wallhaven.cc / w.wallhaven.cc，
     可自行增删——将来接入其他站点流量时按域名决定是否走代理链路。
  ② 反代地址：可填多行按序尝试（CF Worker 或自建服务器均可，
     搭建见随包「反代搭建指引.txt」或页内「反代搭建指引」按钮）。
     填了反代后基本一劳永逸，不再依赖任何免费代理。
  ③ 用户代理池：每行一个，支持内嵌账密
     （socks5://user:pass@1.2.3.4:1080 / http://1.2.3.4:8080）
  ④ 公共代理池：程序自动从全网源探测产出（只读），
     超过 6 小时或池内不足 2 个才会自动刷新（尽量减少后台动作）
  ⑤ 代理池源地址：每行「协议|URL」，留空用内置默认源
  按钮：
    · 优选代理   —— 从现有链路实测最快一级并切换（不抓新源，秒级完成）
    · 优选代理池 —— 从源地址全量抓取 → 两轮竞速实测 → 保留最优 5 个
    · 更新代理源 —— 重置为内置默认全网源并立即开始优选
    · 恢复默认源 —— 仅把源列表恢复为内置默认
    · 反代搭建指引 —— 打开随包指引（CF Worker / 自建服务器两种方案）
  所有地址框停止输入 700ms 即自动保存并即时生效，无需点保存。

  —— 供其他程序集成 ——
  代理逻辑收敛在无 UI 依赖的 ProxyModule（Core/ProxyModule.cs，单文件可拷贝复用）：
    · ProxyModule.NeedProxy(url, cfg)  判断 URL 是否命中代理规则
    · ProxyModule.Route(url, cfg)      路由决策与说明
    · ProxyModule.Snapshot(cfg)        导出代理配置快照（JSON）
  自检演示：PonyoWallpaper-1.0.0-x64.exe --proxy-snapshot

【hosts 管理（代理管理 → hosts 管理 页）】
  ※ hosts 是"最后手段"：默认不会自动替换系统 hosts。
    建议先试 直连 / 反代 / 代理池，都不行时再来本页添加映射。
  按钮：
    · 更新 hosts   —— 从源地址拉取 wallhaven 映射写入系统 hosts（需管理员）
    · 移除 hosts   —— 只删本程序写入的标记段，其他条目不受影响
    · 打开 hosts   —— 用记事本打开系统 hosts
    · hosts 测试   —— 实测 API 搜索 / 缩略图 / 原图 三个端点是否可达，
                      并显示当前解析到的 IP（用来核对 hosts 有没有生效）
    · 更新 hosts 源 —— 从候选源（含加速地址组合）实测取最优 5 个并回填
    · 恢复默认源    —— 源地址与加速地址一并恢复内置默认
  内置 3 个每日更新的源（oopsunix 主源 / jocay 镜像 / jsDelivr CDN），
  拉取策略：先直连全部源地址 → 全部不通再逐个套加速前缀重试。
  仅写入/移除 "# wallhaven Hosts Start/End" 标记段，不动其他条目。
  ※ 实测说明：wallhaven 的封锁在 TLS SNI 层而非 DNS 层，
    hosts 方案对它的效果有限，首选仍是反代。

【数据位置】
  %LOCALAPPDATA%\PonyoWallpaper\
    cache\  本地缓存（原图 + 缩略图，LRU 淘汰；
            目录可在设置「缓存地址」中修改，重启生效）
    data\   config.json 配置、history.db 更换记录、收藏/黑名单
    logs\   滚动日志（设置「打开日志」可直接查看）

【自检命令】
  PonyoWallpaper-1.0.0-x64.exe --test-rotate
    （自动搜索→下载→设置一张壁纸，验证全链路，无界面）
  PonyoWallpaper-1.0.0-x64.exe --proxy-snapshot
    （输出代理配置快照 JSON + 代理规则命中自检，供集成参考）
  两者均可与常驻实例同时运行，日志支持多进程写入。
